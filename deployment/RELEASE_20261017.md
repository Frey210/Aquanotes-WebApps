# Monitoring workspace — 17 Oktober 2026

Prioritas pengguna: monitoring harian dan grafik. Implementasi langsung pada React existing, mempertahankan branding Aquanotes–Aerasea.

- Navigator perangkat dengan pencarian nama, UID, lokasi, dan filter konektivitas.
- Nilai sensor menjadi pemilih parameter grafik dengan state selected dan keyboard focus.
- Grafik mendahului tabel fleet; tabel fleet dan angka pengukuran dapat dibuka sesuai kebutuhan.
- Pada layar kecil navigator menjadi select dan nilai sensor tersusun tiga kolom.
- Nilai nol tetap valid; null menghasilkan gap grafik atau empty state jika seluruh data kosong.
- Batas sensor hanya digunakan untuk perangkat yang sesuai selama perpindahan device.
- Navigasi shell, hierarki heading, timestamp, dan branding dipertahankan konsisten.
